Welcome to the Marketplace Listing Quality Reviewer, a human-in-the-loop application built with React, Express, TypeScript, Prisma, Supabase Postgres, and Gemini.

The frontend provides focused workflows for the dashboard, manual listing creation, Excel batch import, and field-level review decisions. The backend separates runtime validation, duplicate detection, policy retrieval, AI response validation, persistence, and structured logging.

Reviewers can see every listing and its current state, including pending, evaluating, needs changes, approved, and failed.

To demonstrate the complete workflow, we create a health and wellness listing containing the risky claim, guaranteed instant back pain cure.

Before Gemini is called, deterministic checks validate required fields, category, price format, text limits, and duplicates.

The policy engine then retrieves only relevant guidance. For this example, it selects the medical claims policy, the absolute claims policy, and clear writing guidance. These exact policy codes form the citation allowlist.

Gemini receives the listing and retrieved context. It returns structured JSON with the affected field, issue type, severity, evidence, policy code, and suggested wording. The backend validates both the schema and every citation before saving the result.

The critical medical claim appears in the review workbench. The reviewer can approve the suggestion, edit it, or reject the finding. No AI wording is applied automatically.

After every finding has a decision, finalization creates an immutable revised listing. The original submission, review attempt, finding, human decision, approved revision, and audit event remain preserved.

Excel batches use the same workflow for up to twenty listings, while failures remain isolated. The result is a complete, tested, policy-grounded, and auditable review application.
